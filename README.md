# Maze Generator and Solver

A Python application that generates random mazes and solves them using Pygame.

## Features
- Random maze generation using Depth-First Search algorithm
- Maze solving using A* pathfinding algorithm
- Interactive visualization using Pygame
- Ability to generate new mazes and visualize the solving process

## Requirements
- Python 3.8 or higher
- Pygame
- NumPy

## Installation
1. Clone this repository
2. Install the required packages:
```bash
pip install -r requirements.txt
```

## How to Run
Run the main game file:
```bash
python main.py
```

## Controls
- Space: Generate new maze
- Enter: Solve current maze
- ESC: Quit game
